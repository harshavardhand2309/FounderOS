## 2. Technique catalogue — cliché vs. fresh

### 2.1 Retire

| Technique | Why |
| --- | --- |
| Full-page scroll-jacking (one panel per wheel event) | Breaks scrollbar, arrow keys, assistive-tech mapping |
| Percentage preloader 0→100 | The most reliable dating signal on the creative web |
| Fade-up-on-scroll on every element | Named as *the* exhausted pattern. Animate 2–3 things per page |
| Circle cursor + `mix-blend-mode: difference` | The most-copied interaction on the creative web |
| Constant-speed brand-word marquee | Template-tier |
| PavelDoGreat fluid sim as background | Instantly recognisable copy-paste; reads 2021 |
| 2018 displacement-map image hover | Most-cloned WebGL effect; survives only with a bespoke, material-referential map |
| Cursor image trail | Peaked 2022–23 |
| Single 3D object floating in a void as hero | 2026 shift is explicitly away from this |
| Character-level split-text on every heading | Line-level, once per page, is the surviving form |
| Parallax on hero *and* every section | Cliché, but fine sparingly at high magnitude as a deliberate reveal |
| Infinite draggable scattered image canvas | The defining 2024–25 effect; now saturated |
| Site-wide horizontal scroll | Wrecks find-in-page, `Home`/`End`, trackpads, mobile |
| Dark purple-gradient SaaS · gradient blobs · 3D blob heroes · heavy glass · borrowed brutalism | Each died the moment it became free via template/preset/generator |

### 2.2 Still fresh

| Technique | Why |
| --- | --- |
| **Cross-document View Transitions** — `@view-transition { navigation: auto }` | One CSS line, grid→PDP image morph across real navigations, GPU-composited, no JS. **Highest ROI item in the research.** Still badly under-deployed. |
| **Native CSS scroll-driven animations** — `animation-timeline: view()` | Off-main-thread, no library, ~84–90% support. Correct 2026 default for reveals. *But: now a commodity, so it earns zero creativity points.* |
| **Real cloth simulation** | Almost nobody ships genuine drape. Most on-brief, least commoditised effect in fashion. |
| **Composite/render-target WebGL** — post-processing the whole composited page | The 2026 technical frontier ([Codrops](https://tympanus.net/codrops/2026/02/23/composite-rendering-the-brilliance-behind-inspiring-webgl-transitions/)) |
| **Scroll velocity as animation input** — bend, skew, blur, `timeScale` | Physically legible, ~15 lines, immediately differentiating |
| **Variable-font axis animation on scroll** — `@property` + `animation-timeline` | Needs a licensed variable font, which keeps it out of template-land |
| **"One hero moment" strategy** — fast editorial site, exactly one set piece | Reads as confidence rather than compensation |
| **Rive state machines** over Lottie for interactive UI | Lottie has no scripting layer |
| **Reduced-motion as a designed variant** | Art-directing the still version is now a craft signal to juries |

### 2.3 Cloth simulation — the three tiers

| Approach | How | Cost | Use when |
| --- | --- | --- | --- |
| **Blender-baked** | Simulate in Blender, export vertex animation as MDD (or Alembic → glTF morph targets), play back on scroll | Low runtime, larger file | Hero moment, deterministic motion. [Codrops guide](https://tympanus.net/codrops/2025/08/20/exporting-a-cloth-simulation-from-blender-to-an-interactive-three-js-scene/) |
| **CPU Verlet** | Particle grid + distance constraints, relaxed over N iterations, wind + gravity | Medium; ~30×30 grid ceiling on mobile | Interactive flag/scarf/banner |
| **WebGPU compute** | Constraint solve in a compute pass | High complexity, best fidelity, WebGPU-gated | 2026 frontier; needs a fallback |

### 2.4 Key implementation notes

**Lenis + GSAP — single RAF loop.** Never run Lenis's own `raf` alongside GSAP's ticker:

```js
lenis.on('scroll', ScrollTrigger.update)
gsap.ticker.add((t) => lenis.raf(t * 1000))
gsap.ticker.lagSmoothing(0)
```

`lerp: 0.08–0.12` is the luxury band. **`syncTouch: false`** — smoothing touch fights iOS momentum
and tanks INP. Set `html { scroll-behavior: auto }` or Lenis desyncs from find-in-page.

**Horizontal rails need `containerAnimation`.** Per-item ScrollTriggers inside a horizontal track
compute start/end against *vertical* scroll otherwise, and everything fires at once.

**Variable-font animation needs `@property`.** Without registering the custom property as
`<number>`, the browser treats it as a string and the transition snaps instead of interpolating:

```css
@property --wght { syntax: '<number>'; initial-value: 200; inherits: false; }
```

**View Transitions: one element per name at a time.** Duplicate `view-transition-name` values are
the #1 source of errors — scope the name to the clicked card.

**Image sequences: canvas, not `<video currentTime>`.** Backward scrubbing and frame-accurate
seeking are unreliable cross-browser; iOS Safari won't seek smoothly without a user gesture. GSAP
ships [`imageSequenceScrub`](https://gsap.com/docs/v3/HelperFunctions/helpers/imageSequenceScrub/).
Budget ~8–14 MB for 180 frames at 1440px WebP. WebCodecs is the modern middle path.

**`gsap.quickTo` for pointermove handlers** — avoids allocating a tween per event, which is the
difference between smooth and INP-hostile.

## 3. Competitive landscape

### 3.1 The five design languages of the category

Each has distinct tells. Naming them is how you avoid them.

1. **"Enterprise PLM Beige"** *(Centric, Optitex, Lectra, Bamboo Rose)* — mega-menu, stock photo of
   a smiling merchandiser, corporate blue, grayscale logo wall, Gartner badges, everything gated,
   three-column icon grids (*Efficiency / Collaboration / Visibility*), fake dashboard in fake
   browser chrome.
2. **"3D CAD Showcase"** *(CLO, Browzwear, Style3D)* — garment rotating on a **featureless grey
   mannequin** against black, near-black UI with one neon accent, before/after 2D→3D slider.
   **Fatal problem: these renders are now fungible across vendors.** Render quality stopped being a
   differentiator around 2022.
3. **"Indian/SEA B2B Bright"** *(Fashinza, Groyyo, Zyod, Geniemode)* — saturated single brand
   colour, rounded cards, flat vector factories/trucks/handshakes, animated stat counters on a
   colour band, split "For Brands / For Manufacturers" nav. Reads like a fintech landing page with
   garments pasted in.
4. **"Sustainability Sage"** *(TrusTrace, Retraced, Carbonfact, Fairly Made)* — sage/forest green +
   cream, editorial serif to signal "considered" (**now itself a cliché**), world map with pulsing
   supply-chain nodes, regulation-as-fear framing.
5. **"AI-Native 2024–26 Default"** *(StitchSense, StitchProof, most new entrants)* — `#0A0A0A`,
   Inter/Geist, noise overlay, purple→blue gradient glow, bento grid, "Meet your AI co-pilot
   for ___", animated terminal, infinite logo marquee, visible shadcn/Vercel defaults.
   **Tell: indistinguishable from an AI devtools company. Zero fashion signal.**

### 3.3 Six mechanisms for bridging emotional/visual and rational/technical

Ranked by transferability:

1. **Let the output be the emotion; let the interface be the reason** *(Raspberry AI, CLO)* — show
   the beautiful garment, always framed inside product chrome, so beauty is *evidence of the
   software*. One rectangle doing two jobs.
2. **Make the physical object the hero** *(unspun's Vega, VIZOO's xTex scanner)* — industrial
   photography is the rare medium that reads as craft *and* engineering with no translation.
3. **Render data in the visual language of the thing measured** *(Heuritech)* — dissolves the split
   rather than balancing it.
4. **Vocabulary as the credential** — SMV, DHU, OTIF, shade band, lay plan, cut-to-ship, line
   balancing, grade rule. Jargon is free credibility; adjectives cost trust.
5. **Numbers, not adjectives** — Zyod, unspun, ZOZO (3.7mm vs a laser scanner), and Carbonfact's
   PwC audit.
6. **Restraint as the luxury signal** — in fashion the credibility cue is not ornament, it's
   confidence. The only move that satisfies both audiences without compromise, and the cheapest to
   execute well.

## 4. Awwwards mechanics

**Scoring:** Design 40% · Usability 30% · Creativity 20% · Content 10%.
Minimum **18 jurors**; the **3 scores furthest from the average are discarded**. Voting runs
5 days. A site with high jury scores *plus* ≥10 PRO user votes can win SOTD early. Sites have up
to 3 months from approval to win. **≥6.5 earns an Honorable Mention.**

**Consequences:**

- Design + Usability = **70%.** The "Awwwards rewards wild experiments" model is wrong.
- The outlier-discard rule **structurally advantages consensus-pleasing work** over provocative
  work. You need 15 jurors to broadly agree, not 3 to evangelise.
- **Performance is not a scored criterion.** It sits unnamed inside Usability, judged subjectively
  by designers on fast hardware. This is the structural reason award sites are heavy — nothing in
  the scoring function penalises a 12 MB page that feels smooth on a MacBook Pro.
- HM is a *threshold* (clear 6.5); SOTD is a *competition* (beat a 5-day cohort). **Submission
  timing is a real lever.**
- Accessibility is **not** a criterion either. Awwwards' own site uses a desktop hamburger menu.

**Mobile Excellence Award** (with Google): separate mobile-expert panel, four criteria (Mobile
Friendliness, Performance, Best Practices/PWA, Usability), **≥75/100 earns the badge regardless of
SOTD**. Fixed threshold, not a competition — and the WebGL-showpiece cohort is structurally bad at
it. Best effort-to-reward ratio on the board.

**Gap:** no direct juror commentary found on what judges are tired of seeing. Worth browsing
Awwwards juror interviews manually.

### Library accessibility support — verified by source inspection

| Library | Reduced-motion support |
| --- | --- |
| **Motion** | Best in class. `useReducedMotion()`, `useReducedMotionConfig()`, `<MotionConfig reducedMotion="user">` — one provider makes the whole tree respect the OS setting |
| **GSAP** | Good but opt-in. `gsap.matchMedia()`. **`SplitText` has a real `aria` option** (`auto`/`hidden`/`none`) putting `aria-label` on the parent and `aria-hidden` on split chars |
| **Lenis** | **None.** Grepping the shipped `lenis.mjs` for `prefers-reduced-motion`, `reducedMotion` and `matchMedia` returns **zero matches.** Must be gated manually |

```js
// The highest accessibility-value-per-character change available on a site like this
const reduce = matchMedia('(prefers-reduced-motion: reduce)')
if (!reduce.matches) { const lenis = new Lenis(); /* rAF loop */ }
```

### Stalled / dead

- **Theatre.js** — `@theatre/core`, `@theatre/studio`, `@theatre/r3f` all still v0.7.2, last
  published **2024-05-19, over 26 months ago**. "1.0 around the corner, development moved to a
  private repo" has been the public line for a long time. Do not put on a critical path.
- **Locomotive Scroll v4** — faked scroll with transforms, broke sticky/anchors/find-in-page. v5 is
  a thin wrapper around Lenis (sole dependency: `lenis@1.3.17`) and is fine.
- **`gsap-trial`** — formally deprecated in favour of standard `gsap`.
